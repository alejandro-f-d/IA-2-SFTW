# Use Case

Este proyecto busca explorar la similitud de un paper con los ya existentes en la red, en base a las keywords del documento, el significado semántico, autores e instución. Para ampliar la base de conocimiento respecto a los papers cargados y poder calcular de manera más sencilla la similitud entre artículos el sistema se nutre de Wikidata, ORCID y OPENALEX. El usuario recibe de información los papers que tienen un mayor índice de similaridad en base al paper de entrada.
